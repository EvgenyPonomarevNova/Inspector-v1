# Inspector Quadro — first screen concept

Открыть `index.html` в браузере.

Что внутри:
- переработанный первый экран с реальными графическими материалами из архива `фигма.zip`;
- 4 переключаемых рекламных сюжета;
- быстрый модуль входа в подбор препарата;
- подготовленный промо-слот;
- подключение к папке с роликами через кнопку «Смотреть кампанию».

Структура:
- `index.html` — основной прототип;
- `assets/` — изображения животных, упаковок и рекламных баннеров;
