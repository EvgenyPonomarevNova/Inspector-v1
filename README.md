# Inspector Quadro — концепт редизайна лендинга «Можно»

Визуальный прототип редизайна https://inspector.ekoprom.org под рекламную кампанию «Можно».
Работают только анимации и интерфейс (слайдеры, модалки, аккордеоны, подбор на демо-данных), реальных отправок нет.

## Запуск
Статический сайт: открыть `index.html` или выложить папку на любой хостинг (GitHub Pages, Netlify, Vercel).
Нужны: `index.html`, `css/`, `js/`, `img/`. Папка `assets/` — исходники PNG, на сайте не используется.

## Структура страницы
1. Первый экран-плакат «МОЖНО»: фоны кампании из Figma, буквы между фоном и животным (как в KV), 4 сюжета, переключение вручную диагональной шторкой, параллакс. Сюжет из URL: `?scene=british|jack|maine|saint`.
2. Промо-слот для трейд-маркетинга (промокод, магазин, срок) — управляется из Битрикс.
3. Подбор препарата: кошка/собака, точный вес (поле + ползунок + быстрые значения), возраст, особые состояния → карточки SKU или экран «нужна консультация».
4. «4 сезона защиты» — полноэкранный слайдер с фото сезонов (автосмена 7 с, пауза при наведении, свайп, стрелки клавиатуры).
5. 4 группы паразитов — компактные карточки.
6. Весь ассортимент — слайдер по формам + ушные капли отдельным блоком.
7. Как применять — шаги по форме + PDF.
8. Активность клещей по месяцам (карта регионов вынесена на отдельную страницу).
9. Где купить — 5 основных магазинов + «Показать ещё».
10. Полезно знать (FAQ по формам).
11. Служба заботы — телефон и форма (валидация, состояния отправки и успеха).

Окно «Где купить» у каждой карточки: прямые ссылки 4 Лапы / Petshop / ЗооОптТорг, маркетплейсы — брендовый поиск, остальные — под «Показать ещё».

## Что заменить на реальные материалы
- Логотип, упаковки 14 SKU и логотипы магазинов пока подгружаются с текущего сайта (hotlink). Новые упаковки есть только для 4 SKU (`img/product-*.webp`).
- Данные подбора (границы веса, возраст, ограничения), ответы FAQ, шаги применения — демо, заполняются по утверждённой таблице SKU и инструкциям.
- Промокод, график активности клещей — примеры.
- Фото сезонов подгружаются с Unsplash (бесплатная лицензия, автор подписан на слайде). Для продакшена лучше скачать и положить в `img/`.
- Логотип — из Figma (`img/logo-white.png`), тёмная версия для белой шапки собрана из него (`img/logo-dark.png`).

## Шрифты
Fira Sans Extra Condensed (дисплей, наклонный) + Golos Text (текст), Google Fonts. Для продакшена — self-host WOFF2.
